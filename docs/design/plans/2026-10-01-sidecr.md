# Sidecr Implementation Plan

> Written when the project was still called herdr-pal (renamed Sidecr on 2026-10-02). The names below are the current ones; the Task 0 spike scratch names (`pal-scratch`, `pal-spike`, `nazz.pal-noop`) are unchanged.

> This is the original build plan, kept as a design record. For the public release (2026-10-08) the design documents moved to `docs/design/`: the spike notes the plan creates as `docs/spike-findings.md` now live in `docs/design/spike-findings.md`. The README and `docs/` describe what the code does today; where they differ from this plan, they win.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A companion window for herdr: one chord opens a compact chat (last two exchanges) bound to the focused Claude Code pane, with paperclip/paste/drag attachments, image previews, clickable links and a pane switcher.

**Architecture:** A herdr plugin action starts (or reuses) a local Bun server and opens an Edge/Chrome/Chromium `--app` window on it. The server reads the tail of the pane's Claude transcript (`~/.claude/projects/.../<session-id>.jsonl`), pushes change events over SSE, and delivers messages into the pane with the `herdr` CLI (`pane send-text` / `send-keys`). The UI is plain TypeScript bundled by Bun.

**Tech Stack:** Bun 1.3, TypeScript, `bun test`, herdr 0.9.x CLI and plugin system, Chromium-family browser in `--app` mode.

**Spec:** `docs/design/specs/2026-10-01-sidecr-design.md`

## Global Constraints

- Runtime is Bun; the plugin starts it as `bun`, which must be on the PATH herdr's daemon sees.
- herdr plugin manifest: `min_herdr_version = "0.9.0"`, `platforms = ["linux", "windows"]`.
- Server binds `127.0.0.1` only; every request needs a random token (cookie, bootstrapped by `/?t=<token>`) and a `Host` header of `127.0.0.1:<port>` or `localhost:<port>`.
- Show the last **2** exchanges. Start by reading the last **512 KiB** of the transcript; widen (doubling, up to 8 MiB) only if fewer than 2 exchanges are found.
- Attachments: max **25 MiB** each, saved under the state directory `attachments/` with user-only permissions, sent as `@<absolute path>` mentions appended to the message.
- Never use `herdr terminal attach --takeover`; Sidecr never attaches to the terminal.
- Browser order: Edge, then Chrome, then Chromium; launched with `--app=<url>` and its own `--user-data-dir`.
- UI is plain TypeScript, no framework. Transcript text is untrusted: render only with `textContent`/text nodes, never `innerHTML`.
- Windows and Linux must both work; no POSIX-only or Windows-only code outside `src/os.ts` and `src/browser.ts`.
- Commits end with the `Co-Authored-By` and `Claude-Session` trailers used by the existing commits in this repo.

## Review Focus

Inputs the spec implies but no task's happy path exercises, most likely first:

1. The latest exchange's user prompt sits outside the 512 KiB tail because Claude produced huge tool output after it: expect that exchange still shown (Task 2 test).
2. Claude Code starts a new session id after `/clear` or `/resume` while the window is open: expect the window to follow the pane's current session, not show the old conversation (Task 5 test).
3. An uploaded file with a hostile or odd name (`..\..\x.png`, `con.png`, 300 characters, no extension): expect it saved inside `attachments/` under a safe name (Task 4 test).
4. A stale `server.json` after a crash, or the key pressed twice quickly: expect one healthy server and no crash (Task 6 test).
5. A path in the conversation that contains spaces, or a filename in text that is not a real file: expect no crash and surrounding text intact; the link covers only up to the first space (documented limitation) (Task 3 test).

`src/transcript/locate.ts`:

```ts
import { existsSync, readdirSync } from "node:fs";
import { homedir } from "node:os";
import { join } from "node:path";

export function encodeCwd(cwd: string): string {
  return cwd.replace(/[^a-zA-Z0-9]/g, "-");
}

export function projectsRoot(): string {
  return join(homedir(), ".claude", "projects");
}

export function findTranscript(sessionId: string, cwd: string, root: string = projectsRoot()): string | null {
  const direct = join(root, encodeCwd(cwd), `${sessionId}.jsonl`);
  if (existsSync(direct)) return direct;
  if (!existsSync(root)) return null;
  for (const entry of readdirSync(root, { withFileTypes: true })) {
    if (!entry.isDirectory()) continue;
    const candidate = join(root, entry.name, `${sessionId}.jsonl`);
    if (existsSync(candidate)) return candidate;
  }
  return null;
}
```

```ts
import { closeSync, fstatSync, openSync, readSync } from "node:fs";

export function readTailLines(path: string, maxBytes: number): string[] {
  const fd = openSync(path, "r");
  try {
    const size = fstatSync(fd).size;
    const start = Math.max(0, size - maxBytes);
    const buf = Buffer.alloc(size - start);
    readSync(fd, buf, 0, buf.length, start);
    let text = buf.toString("utf8");
    if (start > 0) {
      const nl = text.indexOf("\n");
      text = nl === -1 ? "" : text.slice(nl + 1);
    }
    return text.split(/\r?\n/).filter((line) => line.length > 0);
  } finally {
    closeSync(fd);
  }
}
```

```ts
export type Block =
  | { kind: "text"; text: string }
  | { kind: "tools"; count: number }
  | { kind: "image"; dataUrl: string };

export interface Exchange {
  id: string;
  user: Block[];
  assistant: Block[];
}

const MAX_INLINE_IMAGE_BYTES = 4 * 1024 * 1024;

export function cleanUserText(text: string): string {
  const cmd = /<command-name>([^<]+)<\/command-name>/.exec(text);
  if (cmd) {
    const args = /<command-args>([^<]*)<\/command-args>/.exec(text)?.[1]?.trim();
    return args ? `${cmd[1]} ${args}` : cmd[1];
  }
  if (/^\s*<local-command-/.test(text)) return "";
  return text.trim();
}

/** null means "not a human prompt" (a tool result), so it must not start an exchange. */
function userBlocks(content: unknown): Block[] | null {
  if (typeof content === "string") {
    const text = cleanUserText(content);
    return text ? [{ kind: "text", text }] : [];
  }
  if (!Array.isArray(content)) return [];
  if (content.length > 0 && content.every((b) => b?.type === "tool_result")) return null;
  const blocks: Block[] = [];
  for (const b of content) {
    if (b?.type === "text" && typeof b.text === "string") {
      const text = cleanUserText(b.text);
      if (text) blocks.push({ kind: "text", text });
    } else if (b?.type === "image" && b.source?.type === "base64" && typeof b.source.data === "string") {
      if (b.source.data.length * 0.75 > MAX_INLINE_IMAGE_BYTES) {
        blocks.push({ kind: "text", text: "[image too large to preview]" });
      } else {
        blocks.push({ kind: "image", dataUrl: `data:${b.source.media_type};base64,${b.source.data}` });
      }
    }
  }
  return blocks;
}

export function parseTranscript(lines: string[], n: number): Exchange[] {
  const exchanges: Exchange[] = [];
  for (const line of lines) {
    let row: any;
    try {
      row = JSON.parse(line);
    } catch {
      continue;
    }
    if (!row || row.isSidechain || row.isMeta) continue;
    if (row.type === "user") {
      const blocks = userBlocks(row.message?.content);
      if (!blocks || blocks.length === 0) continue;
      exchanges.push({ id: String(row.uuid ?? exchanges.length), user: blocks, assistant: [] });
    } else if (row.type === "assistant") {
      const current = exchanges.at(-1);
      if (!current) continue;
      const content = Array.isArray(row.message?.content) ? row.message.content : [];
      for (const b of content) {
        if (b?.type === "text" && typeof b.text === "string" && b.text.trim()) {
          current.assistant.push({ kind: "text", text: b.text });
        } else if (b?.type === "tool_use") {
          const last = current.assistant.at(-1);
          if (last?.kind === "tools") last.count += 1;
          else current.assistant.push({ kind: "tools", count: 1 });
        }
      }
    }
  }
  return exchanges.slice(-n);
}
```

```ts
export function loadExchanges(
  path: string,
  n: number,
  startBytes: number = TAIL_BYTES,
  maxBytes: number = TAIL_MAX_BYTES,
): Exchange[] {
  const size = statSync(path).size;
  let window = startBytes;
  for (;;) {
    const exchanges = parseTranscript(readTailLines(path, window), n);
    if (exchanges.length >= n || window >= size || window >= maxBytes) return exchanges;
    window = Math.min(window * 2, maxBytes);
  }
}
```

```ts
export interface Token {
  type: "text" | "url" | "path";
  value: string;
}

const urlPattern = String.raw`https?:\/\/[^\s<>"'\x60)\]]*[^\s<>"'\x60)\].,;:!?]`;
const winPattern = String.raw`[A-Za-z]:\\(?:[^\\/:*?"<>|\s\x60]+\\)*[^\\/:*?"<>|\s\x60]+`;
const posixPattern = String.raw`(?<![\w/.:-])~?(?:\/[\w.@+-]+)+`;
const RE = new RegExp(`(${urlPattern})|(${winPattern})|(${posixPattern})`, "gu");

export function tokenize(text: string): Token[] {
  const out: Token[] = [];
  let last = 0;
  for (const m of text.matchAll(RE)) {
    const type = m[1] ? "url" : "path";
    let value = m[0];
    if (type === "path") value = value.replace(/[.,;:!?]+$/, "");
    const start = m.index ?? 0;
    if (start > last) out.push({ type: "text", value: text.slice(last, start) });
    out.push({ type, value });
    last = start + value.length;
  }
  if (last < text.length) out.push({ type: "text", value: text.slice(last) });
  return out;
}
```

```ts
import { existsSync, mkdirSync, readdirSync, statSync, unlinkSync, writeFileSync } from "node:fs";
import { join, resolve } from "node:path";

const RESERVED = /^(con|prn|aux|nul|com[1-9]|lpt[1-9])(\..*)?$/i;

export function sanitizeName(name: string): string {
  let base = name.split(/[\\/]/).pop() ?? "";
  base = base.replace(/[^\w.\-]+/g, "-").replace(/^[.\-]+/, "");
  if (base.length > 80) {
    const dot = base.lastIndexOf(".");
    const ext = dot > 0 && base.length - dot <= 10 ? base.slice(dot) : "";
    base = base.slice(0, 80 - ext.length) + ext;
  }
  if (!base || /^\.+$/.test(base)) return "file";
  return RESERVED.test(base) ? `_${base}` : base;
}

function stamp(d: Date): string {
  const p = (n: number) => String(n).padStart(2, "0");
  return `${d.getUTCFullYear()}${p(d.getUTCMonth() + 1)}${p(d.getUTCDate())}-${p(d.getUTCHours())}${p(d.getUTCMinutes())}${p(d.getUTCSeconds())}`;
}

export function saveAttachment(dir: string, name: string, bytes: Uint8Array, now: Date = new Date()): string {
  mkdirSync(dir, { recursive: true, mode: 0o700 });
  const base = `${stamp(now)}-${sanitizeName(name)}`;
  let target = resolve(join(dir, base));
  for (let i = 1; existsSync(target); i++) target = resolve(join(dir, `${i}-${base}`));
  writeFileSync(target, bytes, { mode: 0o600 });
  return target;
}

export function buildMessage(text: string, paths: string[]): string {
  const body = text.replace(/\r\n/g, "\n").trim();
  const mentions = paths.map((p) => `@${p}`).join(" ");
  return [body, mentions].filter(Boolean).join(" ");
}

export function pruneOld(dir: string, maxAgeMs: number, now: number = Date.now()): number {
  if (!existsSync(dir)) return 0;
  let deleted = 0;
  for (const name of readdirSync(dir)) {
    const p = join(dir, name);
    try {
      if (statSync(p).isFile() && now - statSync(p).mtimeMs > maxAgeMs) {
        unlinkSync(p);
        deleted++;
      }
    } catch {
      /* file vanished or locked: leave it */
    }
  }
  return deleted;
}
```

```ts
export type Exec = (cmd: string[]) => Promise<ExecResult>;

export const defaultExec: Exec = async (cmd) => {
  const proc = Bun.spawn(cmd, { stdout: "pipe", stderr: "pipe" });
  const [stdout, stderr] = await Promise.all([new Response(proc.stdout).text(), new Response(proc.stderr).text()]);
  return { code: await proc.exited, stdout, stderr };

  getPane(id: string): Promise<PaneInfo>;
  listAgentPanes(): Promise<PaneInfo[]>;

function toPane(p: any): PaneInfo {
  return {
    paneId: String(p.pane_id),
    agent: p.agent ?? null,
    agentStatus: String(p.agent_status ?? "unknown"),
    sessionId: p.agent_session?.value ?? null,
    cwd: String(p.cwd ?? ""),
    title: String(p.terminal_title_stripped ?? p.terminal_title ?? p.pane_id),
    workspaceId: String(p.workspace_id ?? ""),
  };
}

export class Herdr implements HerdrLike {
  constructor(
    private exec: Exec = defaultExec,
    private bin: string = process.env.HERDR_BIN_PATH ?? "herdr",
  ) {}

  private async call(args: string[]): Promise<any> {
    const res = await this.exec([this.bin, ...args]);
    if (res.code !== 0) throw new HerdrError(res.stderr.trim() || res.stdout.trim() || `herdr exited with ${res.code}`);
    try {
      return res.stdout.trim() ? JSON.parse(res.stdout) : {};
    } catch {
      throw new HerdrError("herdr returned output that is not JSON");
    }
  }

  async getPane(id: string): Promise<PaneInfo> {
    const out = await this.call(["pane", "get", id]);
    if (!out?.result?.pane) throw new HerdrError(`pane ${id} not found`);
    return toPane(out.result.pane);
  }

  async listAgentPanes(): Promise<PaneInfo[]> {
    const out = await this.call(["agent", "list"]);
    return (out?.result?.agents ?? []).map(toPane);
  }

  async readScreen(id: string): Promise<string> {
    const res = await this.exec([this.bin, "pane", "read", id]);
    if (res.code !== 0) throw new HerdrError(res.stderr.trim() || `could not read pane ${id}`);
    return res.stdout;
  }

  async sendText(id: string, text: string): Promise<void> {
    await this.call(["pane", "send-text", id, text]);
  }

  async sendKeys(id: string, keys: string[]): Promise<void> {
    await this.call(["pane", "send-keys", id, ...keys]);
  }
}

export function assertSendable(pane: PaneInfo, screen: string): void {
  if (pane.agent !== "claude") throw new SidecrError("not-claude", "this pane is not running Claude Code");
  const tail = screen.split(/\r?\n/).filter((l) => l.trim() !== "").slice(-MENU_SCAN_LINES).join("\n");
  if (BLOCKED_STATUSES.includes(pane.agentStatus) || MENU_MARKER.test(tail)) {
    throw new SidecrError("menu-open", "a menu is open in the terminal; answer it there first");
  }
}

export async function deliver(
  h: HerdrLike,
  paneId: string,
  message: string,
  mode: DeliveryMode = DELIVERY_MODE,
): Promise<void> {
  const text = message.replace(/\r\n/g, "\n");
  if (mode === "text-enter") {
    await h.sendText(paneId, text);
  } else if (mode === "paste") {
    await h.sendText(paneId, `\x1b[200~${text}\x1b[201~`);
  } else {
    const lines = text.split("\n");
    for (let i = 0; i < lines.length; i++) {
      if (lines[i]) await h.sendText(paneId, lines[i]);
      if (i < lines.length - 1) await h.sendKeys(paneId, [NEWLINE_KEY]);
    }
  }
  await h.sendKeys(paneId, [ENTER_KEY]);
}
```

```ts
        const tick = async () => {
          try {
            if (Date.now() - cache.at > 2000) {
              const c = await conversation(paneId);
              cache = { at: Date.now(), file: c.file, status: `${c.pane.agentStatus}:${c.pane.sessionId}` };
            }
            const size = cache.file && existsSync(cache.file) ? statSync(cache.file).size : -1;
            const sig = `${size}|${cache.status}`;
            if (sig !== last) {
              last = sig;
              controller.enqueue(enc.encode("data: changed\n\n"));
            }
          } catch {
            if (last !== "gone") {
              last = "gone";
              controller.enqueue(enc.encode("data: changed\n\n"));
            }
          }
        };
        timer = setInterval(tick, 500);
        beat = setInterval(() => controller.enqueue(enc.encode(": hb\n\n")), 15000);
        void tick();
      },
      cancel() {
        clearInterval(timer);
        clearInterval(beat);
        stats.sse--;
      },
    });
    return new Response(stream, { headers: { "content-type": "text/event-stream", "cache-control": "no-store" } });
  }

  const server: ReturnType<typeof Bun.serve> = Bun.serve({
    port: opts.port ?? 0,
    hostname: "127.0.0.1",
    idleTimeout: 255,
    async fetch(req): Promise<Response> {
      stats.lastRequest = Date.now();
      const url = new URL(req.url);
      if (!isHostAllowed(req.headers.get("host"), Number(server.port))) return json({ error: "bad-host" }, 403);
      if (url.pathname === "/health") return new Response("ok");

      const viaCookie = tokenMatches(cookieToken(req.headers.get("cookie")), opts.token);
      const viaQuery = url.pathname === "/" && tokenMatches(url.searchParams.get("t"), opts.token);
      if (!viaCookie && !viaQuery) return json({ error: "unauthorized" }, 401);

      try {
        const paneId = url.searchParams.get("pane") ?? "";
        switch (url.pathname) {
          case "/": {
            const headers = new Headers({ "content-type": "text/html; charset=utf-8", "cache-control": "no-store" });
            if (viaQuery) headers.set("set-cookie", `sidecr=${opts.token}; HttpOnly; SameSite=Strict; Path=/`);
            return new Response(Bun.file(join(opts.uiDir, "index.html")), { headers });
          }
          case "/app.js":
            return new Response(Bun.file(join(opts.distDir, "app.js")), { headers: { "content-type": "text/javascript", "cache-control": "no-store" } });
          case "/style.css":
            return new Response(Bun.file(join(opts.uiDir, "style.css")), { headers: { "content-type": "text/css", "cache-control": "no-store" } });
          case "/api/panes": {
            const panes = (await opts.herdr.listAgentPanes()).filter((p) => p.agent === "claude");
            return json({ panes });
          }
          case "/api/conversation":
            return json(payload(await conversation(paneId)));
          case "/api/events":
            return events(paneId);
          case "/api/send": {
            if (req.method !== "POST") return json({ error: "method" }, 405);
            const form = await req.formData();
            const pane = String(form.get("pane") ?? "");
            const text = String(form.get("text") ?? "").trim();
            const files = form.getAll("files").filter((f): f is File => f instanceof File);
            if (!pane || (!text && files.length === 0)) return json({ error: "empty" }, 400);
            assertSendable(await opts.herdr.getPane(pane), await opts.herdr.readScreen(pane));
            const paths: string[] = [];
            for (const f of files) {
              if (f.size > MAX_ATTACHMENT_BYTES) return json({ error: "too-large", name: f.name }, 413);
              paths.push(saveAttachment(opts.attachmentsDir, f.name, new Uint8Array(await f.arrayBuffer())));
            }
            await deliver(opts.herdr, pane, buildMessage(text, paths));
            return json({ ok: true });
          }
          case "/api/file": {
            const target = expandHome(url.searchParams.get("path") ?? "");
            if (!isImagePath(target) || !isAllowedFile(target, await allowedPaths(paneId), opts.attachmentsDir)) {
              return json({ error: "forbidden" }, 403);
            }
            if (!existsSync(target)) return json({ error: "not-found" }, 404);
            return new Response(Bun.file(target), { headers: { "cache-control": "no-store" } });
          }
          case "/api/open": {
            if (req.method !== "POST") return json({ error: "method" }, 405);
            const body = (await req.json()) as { pane?: string; kind?: string; target?: string };
            const target = String(body.target ?? "");
            if (body.kind === "url") {
              if (!/^https?:\/\//i.test(target)) return json({ error: "bad-url" }, 400);
              await opts.opener(target);
              return json({ ok: true });
            }
            const p = expandHome(target);
            if (isBlockedOpenTarget(p) || !isAllowedFile(p, await allowedPaths(String(body.pane ?? "")), opts.attachmentsDir)) {
              return json({ error: "forbidden" }, 403);
            }
            if (!existsSync(p)) return json({ error: "not-found" }, 404);
            await opts.opener(p);
            return json({ ok: true });
          }
          default:
            return json({ error: "not-found" }, 404);
        }
      } catch (e) {
        if (e instanceof SidecrError) return json({ error: e.code, message: e.message }, 409);
        if (e instanceof HerdrError) return json({ error: "herdr", message: e.message }, 502);
        return json({ error: "internal", message: String(e) }, 500);
      }
    },
  });

  return { server, stats };
}
```

```ts
import { existsSync, mkdirSync, readFileSync, unlinkSync, writeFileSync } from "node:fs";
import { homedir } from "node:os";
import { join } from "node:path";

export interface ServerInfo {
  pid: number;
  port: number;
  token: string;
}

export function stateDir(): string {
  return process.env.HERDR_PLUGIN_STATE_DIR ?? join(homedir(), ".config", "sidecr");
}

export function readInfo(dir: string): ServerInfo | null {
  try {
    const raw = JSON.parse(readFileSync(join(dir, "server.json"), "utf8"));
    if (typeof raw.pid === "number" && typeof raw.port === "number" && typeof raw.token === "string") return raw;
  } catch {
    /* missing or corrupt */
  }
  return null;
}

export function writeInfo(dir: string, info: ServerInfo): void {
  mkdirSync(dir, { recursive: true, mode: 0o700 });
  writeFileSync(join(dir, "server.json"), JSON.stringify(info), { mode: 0o600 });
}

export function removeInfo(dir: string): void {
  try {
    unlinkSync(join(dir, "server.json"));
  } catch {
    /* already gone */
  }
}

export async function isHealthy(info: ServerInfo): Promise<boolean> {
  try {
    const res = await fetch(`http://127.0.0.1:${info.port}/health`, { signal: AbortSignal.timeout(800) });
    return res.ok;
  } catch {
    return false;
  }
}

export async function ensureServer(dir: string, spawnServer: () => void, timeoutMs = 6000): Promise<ServerInfo> {
  const existing = readInfo(dir);
  if (existing && (await isHealthy(existing))) return existing;
  removeInfo(dir);
  spawnServer();
  const deadline = Date.now() + timeoutMs;
  while (Date.now() < deadline) {
    const info = readInfo(dir);
    if (info && (await isHealthy(info))) return info;
    await Bun.sleep(100);
  }
  throw new Error(`the Sidecr server did not start within ${timeoutMs} ms (state dir: ${dir})`);
}
```

```ts
export function findBrowser(l: BrowserLookup): string | null {
  if (l.platform === "win32") {
    const pf86 = l.env["ProgramFiles(x86)"];
    const pf = l.env["ProgramFiles"];
    const local = l.env["LOCALAPPDATA"];
    const candidates = [
      pf86 && `${pf86}\\Microsoft\\Edge\\Application\\msedge.exe`,
      pf && `${pf}\\Microsoft\\Edge\\Application\\msedge.exe`,
      pf && `${pf}\\Google\\Chrome\\Application\\chrome.exe`,
      pf86 && `${pf86}\\Google\\Chrome\\Application\\chrome.exe`,
      local && `${local}\\Google\\Chrome\\Application\\chrome.exe`,
    ].filter((c): c is string => Boolean(c));
    return candidates.find((c) => l.exists(c)) ?? null;
```

```ts
  const words = query.toLowerCase().split(/\s+/).filter(Boolean);
  if (words.length === 0) return rows;
  return rows.filter((r) => {
    const hay = `${r.title} ${r.workspaceId}`.toLowerCase();
```

```ts
import { tokenize } from "../src/tokenize";
import type { Block, Exchange } from "../src/transcript/parse";
import { filterPanes, type PaneRow } from "./switcher";

interface Conv {
  pane: { id: string; title: string; status: string; agent: string | null };
  exchanges: Exchange[];
  error?: string;

const $ = <T extends HTMLElement>(id: string) => document.getElementById(id) as T;
const conv = $("conv");
const notice = $("notice");
const tray = $("tray");
const msg = $<HTMLTextAreaElement>("msg");
const sendBtn = $<HTMLButtonElement>("send");
const fileInput = $<HTMLInputElement>("file");

let paneId = new URLSearchParams(location.search).get("pane") ?? "";
let pending: File[] = [];
let source: EventSource | null = null;
let canSend = true;

history.replaceState(null, "", `/?pane=${encodeURIComponent(paneId)}`);

function showNotice(text: string | null) {
  notice.hidden = text === null;
  notice.textContent = text ?? "";
}

async function api<T>(path: string, init?: RequestInit): Promise<T> {
  const res = await fetch(path, init);
  const body = await res.json().catch(() => ({}));
  if (!res.ok) throw Object.assign(new Error((body as any).message ?? (body as any).error ?? res.statusText), { code: (body as any).error, status: res.status });
  return body as T;
}

const fileUrl = (p: string) => `/api/file?pane=${encodeURIComponent(paneId)}&path=${encodeURIComponent(p)}`;

function renderText(text: string): DocumentFragment {
  const frag = document.createDocumentFragment();
  for (const t of tokenize(text)) {
    if (t.type === "text") {
      frag.append(document.createTextNode(t.value));
    } else if (t.type === "url") {
      const a = document.createElement("a");
      a.className = "link";
      a.textContent = t.value;
      a.dataset.kind = "url";
      a.dataset.target = t.value;
      frag.append(a);
    } else {
      const a = document.createElement("a");
      a.className = "link";
      a.textContent = t.value;
      a.dataset.kind = "path";
      a.dataset.target = t.value;
      frag.append(a);
      if (isImagePath(t.value)) {
        const img = document.createElement("img");
        img.className = "thumb";
        img.src = fileUrl(t.value);
        img.alt = "";
        img.onerror = () => img.remove();
        frag.append(img);
      }
    }
  }
  return frag;
}

function renderBlock(b: Block): HTMLElement {
  if (b.kind === "tools") {
    const d = document.createElement("div");
    d.className = "tools";
    d.textContent = `${b.count} tool call${b.count === 1 ? "" : "s"}`;
    return d;
  }
  if (b.kind === "image") {
    const img = document.createElement("img");
    img.className = "thumb";
    img.src = b.dataUrl;
    img.alt = "";
    return img;
  }
  const d = document.createElement("div");
  d.append(renderText(b.text));
  return d;
}

function render(c: Conv) {
  $("title").textContent = c.pane.title;
  const status = $("status");
  status.textContent = c.pane.status;
  status.className = `pill ${c.pane.status}`;
  const nearBottom = conv.scrollHeight - conv.scrollTop - conv.clientHeight < 80;
  conv.replaceChildren();
  for (const ex of c.exchanges) {
    const u = document.createElement("div");
    u.className = "msg user";
    for (const b of ex.user) u.append(renderBlock(b));
    conv.append(u);
    if (ex.assistant.length) {
      const a = document.createElement("div");
      a.className = "msg assistant";
      for (const b of ex.assistant) a.append(renderBlock(b));
      conv.append(a);
    }
  }
  if (nearBottom || conv.scrollTop === 0) conv.scrollTop = conv.scrollHeight;
  if (c.error === "no-session") showNotice("This pane has no Claude Code session.");
  else if (c.error === "transcript-not-found") showNotice("Transcript not found for this session.");
  else showNotice(null);
  canSend = !c.error;
  sendBtn.disabled = !canSend;
}

async function refresh() {
  try {
    render(await api<Conv>(`/api/conversation?pane=${encodeURIComponent(paneId)}`));
  } catch (e) {
    canSend = false;
    sendBtn.disabled = true;
    showNotice((e as Error).message);
  }
}

function connect() {
  source?.close();
  source = new EventSource(`/api/events?pane=${encodeURIComponent(paneId)}`);
  source.onmessage = () => void refresh();
}

function setPane(id: string) {
  paneId = id;
  history.replaceState(null, "", `/?pane=${encodeURIComponent(paneId)}`);
  pending = [];
  renderTray();
  connect();
  void refresh();
}

function renderTray() {
  tray.replaceChildren();
  pending.forEach((f, i) => {
    const chip = document.createElement("div");
    chip.className = "chip";
    if (f.type.startsWith("image/")) {
      const img = document.createElement("img");
      img.src = URL.createObjectURL(f);
      img.alt = "";
      chip.append(img);
    }
    chip.append(document.createTextNode(f.name));
    const x = document.createElement("button");
    x.type = "button";
    x.textContent = "\u00d7";
    x.onclick = () => {
      pending.splice(i, 1);
      renderTray();
    };
    chip.append(x);
    tray.append(chip);
  });
}

function addFiles(files: Iterable<File>) {
  for (const f of files) {
    const name = f.name && f.name !== "image.png" ? f.name : `image-${Date.now()}.png`;
    pending.push(new File([f], name, { type: f.type }));
  }
  renderTray();
}

async function send() {
  const text = msg.value.trim();
  if (!canSend || (!text && pending.length === 0)) return;
  sendBtn.disabled = true;
  try {
    const form = new FormData();
    form.set("pane", paneId);
    form.set("text", text);
    for (const f of pending) form.append("files", f);
    await api("/api/send", { method: "POST", body: form });
    msg.value = "";
    pending = [];
    renderTray();
    showNotice(null);
  } catch (e) {
    showNotice((e as Error).message);
  } finally {
    sendBtn.disabled = !canSend;
    msg.focus();
  }
}

// Switcher
const overlay = $("overlay");
const q = $<HTMLInputElement>("q");
const list = $<HTMLUListElement>("list");
let rows: PaneRow[] = [];
let shown: PaneRow[] = [];
let sel = 0;

function drawList() {
  shown = filterPanes(rows, q.value);
  sel = Math.min(sel, Math.max(0, shown.length - 1));
  list.replaceChildren();
  shown.forEach((r, i) => {
    const li = document.createElement("li");
    li.className = i === sel ? "sel" : "";
    const name = document.createElement("span");
    name.textContent = `${r.title} (${r.workspaceId})`;
    const st = document.createElement("span");
    st.className = "pill";
    st.textContent = r.agentStatus;
    li.append(name, st);
    li.onclick = () => choose(i);
    list.append(li);
  });
}

function choose(i: number) {
  const row = shown[i];
  if (!row) return;
  closeOverlay();
  setPane(row.paneId);
}

async function openSwitcher() {
  overlay.hidden = false;
  q.value = "";
  sel = 0;
  try {
    const { panes } = await api<{ panes: { paneId: string; title: string; workspaceId: string; agentStatus: string }[] }>("/api/panes");
    rows = panes;
  } catch (e) {
    rows = [];
    showNotice((e as Error).message);
  }
  drawList();
  q.focus();
}

function closeOverlay() {
  overlay.hidden = true;
  msg.focus();
}

q.addEventListener("input", () => { sel = 0; drawList(); });
q.addEventListener("keydown", (e) => {
  if (e.key === "ArrowDown") { e.preventDefault(); sel = Math.min(sel + 1, shown.length - 1); drawList(); }
  else if (e.key === "ArrowUp") { e.preventDefault(); sel = Math.max(sel - 1, 0); drawList(); }
  else if (e.key === "Enter") { e.preventDefault(); choose(sel); }
});

fileInput.onchange = () => { addFiles(Array.from(fileInput.files ?? [])); fileInput.value = ""; };

conv.addEventListener("click", (e) => {
  const el = e.target as HTMLElement;
  if (el instanceof HTMLImageElement && el.classList.contains("thumb")) {

});

window.addEventListener("keydown", (e) => {
  const mod = e.ctrlKey || e.metaKey;

});
```

````markdown
# sidecr

A companion window for [herdr](https://github.com/herdrdev/herdr). One chord opens a compact chat on the focused Claude Code pane: attach files with the paperclip, paste or drag images, see previews, click links and paths, switch pane. herdr and its terminal stay untouched.

## Install

```bash
git clone <this repo> sidecr && cd sidecr
bun install
bun run build:ui
herdr plugin link .
```

Bind a key in herdr's `config.toml` (use the chord found in `docs/spike-findings.md`), then reload:

```toml
[[keys.command]]
key = "ctrl+shift+j"
type = "plugin_action"
command = "nazz.sidecr.open"
description = "sidecr"
```

```bash
herdr server reload-config
```

`bun` must be on the PATH that herdr's daemon sees. If the action logs `No such file or directory` (see `herdr plugin log list`), link bun somewhere on that PATH (`ln -s ~/.bun/bin/bun ~/.local/bin/bun`) and restart herdr from a login shell.

## Use

| Key | Where | Action |
|---|---|---|
| your chord | terminal | open the window on the focused pane |
| `Ctrl+Shift+K` | window | switch to another Claude pane by name |
| `Ctrl+Shift+J` | window | close the window |
| `Enter` / `Shift+Enter` | window | send / new line |

## Remove

`herdr plugin unlink nazz.sidecr`, delete the key block, `herdr server reload-config`.

## Limits

Claude Code only, one pane per window, last two exchanges, no remote machines. A path containing spaces is linked only up to its first space.
````
